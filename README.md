# Architecture Standart

## Описание проекта

Работа спринт 4 по архитектуре ПО.
Проект включает 4 этапа разработки архитектурных решений для банковского приложения.

## Структура проекта

### Task1 - IT-ландшафт и интеграции
- Создание карты IT-ландшафта банка
- Схема интеграции приложений
- Диаграммы: `interation.drawio`, `it-landscape.drawio`

### Task2 - FURPS+ анализ
- Анализ требований по методологии FURPS+
- Документ: `FURPS+.md`

### Task3 - MVP открытия депозитов онлайн
- Архитектурные решения для онлайн-депозитов
- C4 диаграммы (контекст и контейнеры)
- ADR документ: `ADR_1_MVP_открытия_депозитов_онлайн.md`

### Task4 - Дополнение MVP - ставки в кол-центре
- Архитектурные решения для передачи ставок в кол-центр
- C4 диаграммы для кол-центра
- ADR документ: `ADR_2_MVP_ставки_в_кол_центре.md`
- Дорожная карта: `RoadMap_bank_Standart.drawio`
- План работ: `План работ.md`
